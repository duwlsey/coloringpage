# 즐거운 색칠공부

어린이를 위한 색칠공부와 상상 이어 그리기 앱입니다. 기존 11개와 제안 카테고리에 도안 97개(상상 45개, 기존 나머지 카테고리별 5개, 제안 2개)를 제공하며, 카테고리를 넘나들며 선택하고 한 번에 출력할 수 있습니다. 상상 01~10은 닫힌 기본 도형, 11~19는 같은 도형의 왼쪽 세로 절반, 20은 하트의 위쪽 가로 절반, 21~40은 기존 미완성 도안입니다.

## GitHub Pages

Settings → Pages → Build and deployment에서 **Deploy from a branch**를 선택합니다. **main** 브랜치, **/(root)** 폴더를 지정하고 Save를 누르면 됩니다.

## 도안 추가

`drawings.js`의 해당 카테고리에 한국어 이름과 이미지 경로를 추가하고, 이미지 파일을 `images/` 폴더에 저장합니다. 상상 도안은 미완성 SVG 선으로 구성됩니다. 제작 지침과 현재 목록은 `DRAWING-WORKFLOW.md`에 있습니다.

화면에는 `thumbnails/`의 최대 480px WebP 미리보기를 지연 로딩합니다. 새 도안을 추가할 때 `thumbnail` 경로도 함께 지정합니다. 출력에는 `images/`의 고해상도 원본을 사용합니다.

## 글꼴과 출력

제공된 OkDanDan-Bold 글꼴을 웹용 WOFF2로 변환해 포함했습니다. 글꼴이 준비된 뒤 화면을 표시해 처음 접속하거나 새로고침할 때 글꼴이 바뀌는 현상을 방지합니다.

그림 카드 클릭으로 선택·해제하고, 카드의 출력 버튼으로 개별 출력하거나 선택 출력으로 묶음 출력합니다. 브라우저 인쇄 창에서 PDF로 저장할 수도 있습니다. A4 세로, 머리글·바닥글 끄기를 권장합니다.

선택은 현재 페이지를 사용하는 동안 카테고리를 이동해도 유지됩니다. 새로고침하거나 다시 접속하면 모두 해제되며, 브라우저에 선택 기록을 저장하지 않습니다.

제안 기능은 SUGGESTIONS-SETUP.md의 Google Apps Script 연결 후 활성화한다. 연결 전에는 제출을 비활성화한다. 상단 검색은 모든 카테고리의 도안 이름과 검색어를 찾는다.
